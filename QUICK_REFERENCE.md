## 📦 How to Install & Use

### Step 1: Add Marketplace
```bash
/plugin marketplace add wshobson/agents
```

### Step 2: Browse Plugins
```bash
/plugin
```

### Step 3: Install What You Need
```bash
/plugin install python-development
/plugin install backend-development
/plugin install unit-testing
```

### Step 4: Use the Agents
Once installed, agents are automatically available. Just describe what you need:
- "Create a FastAPI project" → Python-Pro agent activates
- "Generate unit tests" → Unit Test Generator activates
- "Review this code" → Code Review AI activates
